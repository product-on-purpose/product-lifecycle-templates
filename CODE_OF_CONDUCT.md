# Code of conduct

## The short version

Be straightforward and be kind. Argue with the work, not the person.

## What this project actually needs from contributors

This is a library whose central claim is honesty about evidence, so the conduct that matters most here is
**intellectual**:

- **Say what you verified and what you assumed.** "I could not retrieve the source" is a valued
  contribution. A plausible claim with no source is the defect this whole repository exists to catch.
- **Take correction on the argument.** Findings here are regularly overturned on verification, including
  the maintainer's own. That is the process working, not a loss.
- **Do not overstate.** Not in a template, not in a research log, not in a pull request description.

## Unacceptable behaviour

Harassment, personal attacks, demeaning comments, unwelcome attention, and publishing others' private
information. Also: **knowingly submitting fabricated sources, citations, or quotations**. In a library that
stakes its credibility on traceable evidence, that is a conduct problem and not only a quality one.

## Scope and enforcement

Applies in issues, pull requests, discussions, and any space representing this project.

Report by opening an issue, or privately through GitHub if the report concerns someone in the thread. The
maintainer will respond and may edit, remove, or reject contributions, or block accounts.

This is a small single-maintainer project. There is no committee and no appeals process. What there is
instead is a commitment to explain any action taken.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), rewritten to say
what this project specifically needs rather than to be portable.
