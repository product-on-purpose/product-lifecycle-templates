# product-lifecycle-templates v0.9.0

Release date: 2026-09-21. This project follows [Semantic Versioning](https://semver.org/).

## Summary

**The library has a website.** All 30 bundles are now readable at
<https://product-on-purpose.github.io/product-lifecycle-templates/> by anyone with a link, instead of
only by someone willing to clone a repository and open eight files per bundle. Every page is generated
from the tree: no bundle is named by hand anywhere in the site.

This is S0, "it exists", and deliberately not the signature experience. What it buys is reach. What it
does not buy is any new claim about whether the templates help anyone.

Two long-open decisions also close here, and a third document type is admitted to a family.

## New

- **A generated site, 34 pages.** `scripts/gen-site.mjs` reads `manifest.json`, `sections.json`,
  `atlas/catalog-data.json` and `templates/`, and writes one Astro Starlight page per bundle plus an
  index. Each page carries the bundle's guide verbatim, its template variants and worked example in
  role tabs, and links out to the companion, history and research log.
- **Five guards, and they run between the build and the upload.** The artifact that is checked is the
  artifact that ships: internal links resolve in a browser, no published route has disappeared, every
  "Edit this page" target is git-tracked, a favicon resolves on every page including `404.html`, and
  no page calls a bundle proven.
- **[ADR 0053](../internal/decisions/0053-launch-coordination-checklist-joins-standing-standards-as-a-tool.md):
  `launch-coordination-checklist` joins `standing-standards` as a `tool`.** Unblocks a spec stalled
  since 2026-09-11. The family's own falsifier settled it, not its membership test.
- **[ADR 0054](../internal/decisions/0054-the-mcp-server-returns-a-uniform-envelope.md): the MCP server
  will return a uniform `{ok, data?, error?}` envelope.** Decided against a measured spike of three
  annotation shapes. **Not yet implemented**; the envelope is a breaking change to a shipping wire
  format, taken now because nothing external calls the server.

## Improved

- **The honesty rule reached a new surface before the surface existed.** No page may call a bundle
  proven, verified or validated, and the build fails if one does. Every bundle shows `beta`, and zero
  real fills is published as zero rather than omitted.
- **The base path now exists in exactly one place.** `scripts/site-base.mjs` holds the literal and
  `astro.config.mjs` imports it, so a validator and the build cannot disagree about the URL.

## Fixed

- **"Edit this page" 404'd on both hand-authored pages, from the day they shipped.** The Starlight
  `editLink.baseUrl` was missing its `site/` segment. Found by the edit-link guard on its first run
  against a real build; no build, and no CI run, could have caught it, because a URL string is
  syntactically valid whether or not it resolves.
- **A promise tag pointed at a bundle id that would never arrive.** `release-notes_meta.yaml` said
  `future:launch-checklist` while the catalog id is `launch-coordination-checklist`, and the gate
  resolves `future:` by bundle id. Building under the catalog id would have left the promise
  unfulfillable with the gate still green.
- **An acceptance criterion whose mutation test could never go red.** The ported edit-link guard now
  asserts targets are git-tracked rather than merely present on disk; the existence check passed on
  exactly the generated, gitignored path the mutation produces.
- **Three more stale self-reported counts**, in `roadmap.md`, `plan.md` and `STATE.md`, two of them
  inside the paragraphs that document the stale-count defect itself.

## What this release does not prove

- **Still zero real fills.** Every filled artifact here, this release note included, is an authored
  example. All 30 bundles remain `beta`, and the site publishes that on every page.
- **A website is reach, not evidence.** Nothing about rendering a bundle to HTML makes it more likely
  to help anyone. The four efficacy runs to date still stand as the only measurement, and the most
  recent found the probe gap at exactly 0.00.
- **Five green guards prove the site is well-formed, never that it is useful.** They check links,
  routes, edit targets, a favicon and forbidden words. None of them reads a sentence for whether it
  is worth reading.
- **One acceptance criterion had no implementation until closeout.** AC-6's favicon guard did not
  exist when the guards PR merged; the favicon resolved, but nothing asserted it. It is written and
  mutation-tested now, and the gap is recorded rather than smoothed over.
- **The MCP envelope is decided, not shipped.** Anything calling the server today still receives the
  old shapes.
