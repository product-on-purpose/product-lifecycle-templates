# product-lifecycle-templates v0.28.1

Release date: 2026-11-26. This project follows [Semantic Versioning](https://semver.org/). This is a patch: no
bundle, template, MCP tool or install route changed, so every document you write today comes out the same.

## Summary

**Both skills now load when you ask for a competitive analysis.** An agent decides whether to load a skill by
reading its description. In v0.28.0 neither description named the new bundle, so a request worded only as
"competitive analysis" missed both skills on every test run. Both descriptions now name it.

## New

- **Nothing new.** No bundle, template, family, MCP tool or install route was added in this release.

## Improved

- **Three names in both descriptions are shorter, to make room.** "Use case specification" is now "use case",
  "retrospective notes" is now "retrospective", and "user persona" is now "persona". Before shipping, a trigger
  test checked each short form. Each one loaded the right skill on 5 of 5 runs.
- **The wording was chosen by a test, not by judgment.** The test ran `claude plugin eval` on Sonnet, with only
  this plugin loaded, over 33 requests at 5 runs each. The new wording loaded the right skill on 163 of 165 runs,
  and the v0.28.0 wording on 156. Two rewrites that shortened more names did worse.

## Fixed

- **A request worded only as "competitive analysis" now reaches the skills.** Before this release it loaded
  neither skill on 5 of 5 test runs. After it, the fill skill loaded on 5 of 5.

## Known issues

- **The next bundle meets the description cap again.** The descriptions measure 1,013 and 1,021 characters
  against a 1,024-character cap, so neither can name another type without dropping or shortening one. A design
  that scales past the cap is being drafted.
- **The trigger test is kinder than a real session.** It loaded only this plugin and used one model. A session
  with many skills installed may load these skills less reliably for every type.
- **Nothing here makes any bundle better.** All 59 are `beta`, and no page calls one proven.
- **The Product on Purpose marketplace lists v0.28.0 until it is re-pinned.** Installing through the marketplace
  serves v0.28.0 until then, which has the same bundles and templates as this release.
- **A search filtered to one axis value can be cut short.** The MCP server's `search_templates` returns at most 8
  candidates, and some axis values hold more bundles than that. `total_matched` in the response tells you when a
  list was cut.
