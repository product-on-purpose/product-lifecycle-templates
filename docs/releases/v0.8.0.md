# product-lifecycle-templates v0.8.0

Release date: 2026-09-14. This project follows [Semantic Versioning](https://semver.org/).

## Summary

**The library grows from 27 bundles to 30, and for the first time it also publishes the reasoning that let
each one in.** The three new document types are a spike report, a project or milestone retrospective, and a
test summary report. A fourth candidate, a PI or release retrospective, was researched alongside them and
**does not ship**, because the evidence said it should not.

If you are choosing a template, the practical news is three new ones. If you are deciding whether to trust
this library, the more useful news is the four decision records explaining exactly how much evidence each
one rests on, including where that evidence is thin.

## New

- **[`spike-report`](../../templates/spike-report/)** - the written record of a time-boxed investigation:
  the question, what was tried, what was found, and a recommendation the next reader can act on. Single
  size. It is the fourth `decision-docs` member, and the one that **investigates** the question an RFC
  proposes, an ADR records, and an SDD designs against.
- **[`project-milestone-retrospective`](../../templates/project-milestone-retrospective/)** - for work that
  has **ended**, as against a sprint retrospective's cadence. Lean for a team retrospective, full for an
  accountability-grade report that must quantify and track previously identified issues.
- **[`test-summary-report`](../../templates/test-summary-report/)** - what was tested, what was found, and
  an evaluation against the plan's exit criteria. It closes the QA chain this library already shipped: the
  plan schedules the case, the case that fails produces the bug report, and this reports the verification as
  a whole.
- **Four decision records that say what the evidence actually was.**
  [ADR 0048](../internal/decisions/0048-one-named-source-clears-the-admission-test.md) settles that one
  named source is enough to admit a document type, because the rule says "a named source", singular.
  [ADR 0049](../internal/decisions/0049-pi-release-retrospective-fails-the-admission-test.md) refuses the PI
  retrospective. [ADR 0050](../internal/decisions/0050-qa-docs-admits-a-fourth-member.md) settles that a
  family contract's exclusion clause governs a candidate where its role list disagrees. And
  [ADR 0047](../internal/decisions/0047-the-usage-precondition-leaves-the-language-too.md) removed the last
  language treating missing usage as a constraint.
- **The pull queue is documented**: [`pull-queue.md`](../reference/pull-queue.md) states how a request is
  weighed, which is honestly rather than decisively.

## Improved

- **Two of the new bundles teach a dispute instead of presenting a settled practice.** The spike report's
  own canon argues against writing one at all: Ward Cunningham's account, crediting Kent Beck, describes the
  output as **throwaway code**. The test summary report's governing standard was the subject of an organised
  campaign to have it **withdrawn**. Both bundles say so, because a bundle that hid it would be claiming
  more than its research supports.
- **A Tier-2 spec sheet** ([`tier2-specs.md`](../internal/tier2-specs.md)) now holds the per-type judgment
  for candidates beyond the Tier-1 floor, which the build runbook required and which did not exist.
- **The `process-docs` and `qa-docs` families each gained a member**, and their contracts were updated in
  the same change rather than left describing a smaller family.

## Fixed

- **`sprint-retrospective-notes` gains the skill pairing it had silently declined.** It shipped with none
  while the paired skill's own description names "the end of a sprint, project, or milestone".
- **Roughly a dozen claims across the library's own documents had aged into being false** and are corrected,
  including counts that were wrong in all three figures and a shipped skill telling readers the library held
  26 bundles when it held 27.

## What this release does not prove

- **Still zero real fills.** Every filled artifact here, this release note included, is an authored example.
  All 30 bundles remain `beta`.
- **The new bundles are researched, not validated.** Nobody outside this repository has filled one.
- **Two of them rest on thin evidence, and their own records say where.** The spike report was admitted on
  **one** named source against its own canon. The test summary report's governing standard is **paywalled**:
  its definition and table of contents were read from an official free preview, its normative text was not,
  and the section design rests on a freely published syllabus instead.
- **A green gate is not a quality claim.** It proves structure and research integrity, never that a document
  helped anyone. The adversarial reviews behind these three bundles found two fabricated quotations and
  eleven overstatements that the gate passed without comment.
