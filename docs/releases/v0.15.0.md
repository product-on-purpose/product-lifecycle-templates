# product-lifecycle-templates v0.15.0

Release date: 2026-09-30. This project follows [Semantic Versioning](https://semver.org/).

## Summary

**The library grows from 35 bundles to 38 with three new templates: a change log, a production readiness
review and a project brief.** The change log is the standing register of every change request a project
receives. The production readiness review checks a service against a standing list before a team takes it
on. The project brief asks a named approver for authority to start finding out whether a project is worth
doing.

None of the three is proven to help anyone. Each is researched, and each says where its sources disagree.
Two further candidates cleared the admission test and were declined, and the decision records say why.

## New

- **[`change-log`](../../templates/change-log/)** - the register behind the change request: one row per
  request against a named baseline, with rejected and postponed rows kept, and the decision recorded apart
  from the status. Lean holds the log and who may decide; full adds how each change was carried out and
  what the changes add up to together.
- **[`production-readiness-review`](../../templates/production-readiness-review/)** - the standing checklist
  a service is reviewed against before the team that will carry its pager takes it on. Each criterion is
  answered with evidence, each not-applicable item gets a reason, and the outcome is Ready, Ready with
  conditions, or Not ready. That vocabulary comes from one practitioner guide, and the template says so.
- **[`project-brief`](../../templates/project-brief/)** - the short document that asks for authority to
  start, before anyone commits to building anything. Lean states the mandate, measurable objectives, what is
  excluded, an outline justification and the decision requested. Full adds the proposed approach and names
  the document that takes over. It builds the lightweight PRINCE2 and UK government sense of the name.

## Improved

- **Every quotation in the three new research logs was checked against the source's raw text**, not a
  retrieval tool's summary.
- **Build-cost reports now count only the agents that built a bundle.** Agents that update the library's
  counts when a bundle lands appear on a separate line. Two reports had folded that work into their totals.
- **The project brief's catalog entry no longer describes a small charter.** The strongest sources describe
  a brief written before initiation on a project of any size.
- **The README's `decision-docs` section names all four jobs**, adding the spike report.

## Fixed

- **The shared worked examples no longer ship Saved Views before it was built.** The release-notes example
  dated version 2.4.0 to 2026-06-30, before the other examples design, build or test the feature. It now
  ships on 2026-07-21, and the change request and change log examples moved with it. This closes the known
  issue listed in `v0.14.0`.
- **The change request bundle said HHS merges the change request form and the change log.** HHS keeps them
  as two documents, and the bundle now carries dated corrections in seven places.
- **The source cache tool crashed on Windows** on any cached page holding a character outside the Windows
  code page, and then reported the page as missing. It could also store piped text garbled.
- **Four sentences used a gendered pronoun for a named person** whose pronouns no source states. They now
  use the person's name.

## Known issues

- **Nothing here makes any bundle better.** All 38 are `beta`, and no page calls one proven.
- **A few smaller inconsistencies remain in the shared examples.** Among them, one example has private views
  live since late June, and another dates general availability to mid-September. Neither affects a template.
- **One search can no longer list a whole phase.** The MCP server's `search_templates` returns at most 8
  candidates, and the `deliver` phase holds 9. `total_matched` in the response tells you when a list was cut.
- **Build cost is measured, not a rate.** The change log cost $16.95 at API list rates, the production
  readiness review $15.75 and the project brief $14.24 ([`bundle-builds/`](../../bundle-builds/INDEX.md)).
