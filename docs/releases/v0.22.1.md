# product-lifecycle-templates v0.22.1

Release date: 2026-10-29. This project follows [Semantic Versioning](https://semver.org/). This is a patch:
no bundle, template, MCP tool or install route changed, so nothing you use today behaves differently.

## Summary

**This library now declares Standard 0.17 of the Advanced Skill Library Standard**, the edition every plugin in
the Product on Purpose marketplace is moving to. It grades Gold at that edition, with no errors and no warnings.
Its CI now runs that grade with agent-skills-toolkit v1.22.0.

## New

- **Nothing new.** No bundle, template, family, MCP tool or install route was added in this release.

## Improved

- **The library declares Standard 0.17, up from 0.12.** Standard 0.17 turned three Gold checks from warnings
  into errors: hook documentation, self-hosting CI and folder READMEs. This library already met all three, so
  the only generated change was `INDEX.md`, whose self-validation line now reads `npx agent-skills-toolkit .`.
  The toolkit grades the library Gold at 0.17, with 0 errors and 0 warnings.
- **CI grades the library with agent-skills-toolkit v1.22.0, up from v1.10.0.** v1.10.0 predates Standard 0.17,
  so it could not grade the new pin. v1.22.0 is also the first toolkit release that stops comparing this
  library's own description of its bundle gate against the toolkit's 35-check count. That comparison reported a
  disagreement that was not real.

## Fixed

- **No user-facing defect is fixed in this release.** The false check-count comparison above affected only this
  repository's CI, and only while the Standard 0.17 change was waiting to merge.

## Known issues

- **Nothing here makes any bundle better.** All 51 are `beta`, and no page calls one proven.
- **The Product on Purpose marketplace still lists v0.22.0 until it is re-pinned.** Installing through the
  marketplace serves v0.22.0 until then, which has the same bundles and templates as this release.
- **A search filtered to one axis value can be cut short.** The MCP server's `search_templates` returns at
  most 8 candidates, and some axis values hold more bundles than that. `total_matched` in the response tells
  you when a list was cut.
