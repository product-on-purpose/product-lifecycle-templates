# Explanation

Explanation pages are for reading away from the keyboard. They give the reasoning behind the design and the honest limits of what it proves.

This folder is one of the four [Diataxis](https://diataxis.fr/) quadrants the
[Advanced Skill Library Standard](../../library.json) requires a published documentation tree to carry.
